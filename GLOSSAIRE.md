# Glossaire anglais → français — Trading Academy

| Anglais | Français | Définition courte |
|---|---|---|
| Ask | Prix acheteur | Prix auquel on peut acheter (le plus haut des deux) |
| Backtesting | Test historique | Tester des règles sur des données passées |
| Balance | Solde | Solde du compte, positions fermées uniquement |
| Bear / Bearish | Ours / Baissier | Marché ou opinion orienté à la baisse |
| Bid | Prix vendeur | Prix auquel on peut vendre |
| Break Even | Point mort | Ni gain ni perte |
| Breakout | Cassure | Sortie franche d'une zone de prix |
| Broker | Courtier | Intermédiaire qui donne accès au marché |
| Bull / Bullish | Taureau / Haussier | Marché ou opinion orienté à la hausse |
| Buy / Long | Acheter / Position acheteuse | Gagne si le prix monte |
| CFD | Contrat sur la différence | Contrat sur la variation d'un prix, sans détenir l'actif |
| Commission | Commission | Frais fixes par transaction |
| Consolidation | Consolidation | Pause du prix, qui se resserre |
| Correction | Correction | Recul temporaire après une hausse |
| Drawdown | Baisse maximale | Baisse du compte d'un sommet à un creux |
| Equity | Valeur nette | Balance ± résultats latents |
| Exposure | Exposition | Valeur totale réellement en jeu |
| Fair Value Gap (FVG) | Déséquilibre de prix | Zone laissée « vide » par un mouvement rapide (3 bougies) |
| Free Margin | Marge libre | Equity − marge utilisée |
| Futures | Contrats à terme | Prix fixé aujourd'hui pour une échéance future |
| Gap | Écart | Saut de prix sans cotation intermédiaire |
| Hedging | Couverture | Réduire un risque par une position opposée |
| Higher High / Higher Low | Sommet / creux plus haut | Structure haussière |
| Leverage | Effet de levier | Exposition supérieure au capital immobilisé |
| Liquidity | Liquidité | Facilité à acheter ou vendre sans faire bouger le prix |
| Lot / Mini / Micro | Lot / 0,1 / 0,01 | 100 000 / 10 000 / 1 000 unités (Forex) |
| Lower High / Lower Low | Sommet / creux plus bas | Structure baissière |
| Margin | Marge | Garantie bloquée par les positions ouvertes |
| Margin Call | Appel de marge | Alerte : Margin Level sous un seuil |
| Margin Level | Niveau de marge | Equity ÷ Marge × 100 |
| Market Order | Ordre au marché | Exécuté immédiatement au meilleur prix |
| Momentum | Élan | Force et vitesse d'un mouvement |
| Pip / Point / Tick | Pip / Point / Tick | 0,0001 sur EUR/USD / 1/10 de pip sur MT5 / plus petit mouvement |
| Position Size | Taille de position | Volume choisi |
| Profit and Loss (P&L) | Résultat | Gain ou perte |
| Prop firm | Société de trading pour compte propre | Fournit un capital après une évaluation payante |
| Pullback | Repli | Retour temporaire contre la tendance |
| Range | Marché latéral | Allers-retours entre un plafond et un plancher |
| Retest | Nouveau test | Retour sur un niveau après une cassure |
| Reversal | Retournement | Changement de tendance |
| Sell / Short | Vendre / Position vendeuse | Gagne si le prix baisse |
| Slippage | Glissement | Écart entre prix demandé et prix exécuté |
| Spread | Écart | Ask − Bid : coût payé à chaque ouverture |
| Stop Loss | Stop de protection | Ferme la position pour limiter la perte |
| Stop Out | Liquidation | Fermeture automatique (50 % de Margin Level pour un particulier dans l'UE) |
| Support / Resistance | Support / Résistance | Zones où le prix a rebondi ou buté |
| Swap | Frais de financement | Coût ou crédit pour garder une position la nuit |
| Take Profit | Prise de bénéfice | Ferme la position à l'objectif |
| Trailing Stop | Stop suiveur | Stop qui suit le prix sans jamais reculer |
| Trend | Tendance | Direction générale du prix |
| Volatility | Volatilité | Amplitude des variations de prix |
| Win rate | Taux de réussite | Part des positions gagnantes |
